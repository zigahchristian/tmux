tmux: Comprehensive Guide & Cheat Sheet

Installation, core architecture, day-to-day command cheatsheets, custom configurations, and full Oh My Tmux! setup.

1. Overview & Core Architecture

tmux (Terminal Multiplexer) lets you run multiple terminal sessions inside a single window, detach from them, and reattach later without interrupting background jobs or active processes—indispensable for local multitasking and remote work over SSH.

Server

The master background daemon managing all sessions, windows, and active terminal processes.

Session

An isolated workspace containing one or more related full-screen windows.

Window

Full-screen views inside a session (analogous to browser tabs).

Pane

Subdivided views within a window (horizontal or vertical terminal splits).

The Prefix Key Concept: Almost all tmux shortcuts are triggered using a prefix key sequence. By default, this is Ctrl + b. Press and release Ctrl + b, then tap your command key (e.g., Ctrl + b followed by c to create a window).

2. Standard Installation

Linux

# Ubuntu / Debian / Linux Mint
sudo apt update && sudo apt install -y tmux

# Fedora / RHEL / CentOS
sudo dnf install -y tmux
# On older CentOS/RHEL systems:
sudo yum install -y tmux

# Arch Linux / Manjaro
sudo pacman -S tmux

# Alpine Linux
apk add tmux

# openSUSE
sudo zypper install tmux

macOS

Install via Homebrew:

brew install tmux

Windows

  • Recommended: Run under WSL (Windows Subsystem for Linux) and install using the distribution's package manager (sudo apt install tmux).
  • Alternative: Install inside MSYS2 or Git Bash (pacman -S tmux).

4. Manual Configuration (~/.tmux.conf)

If you prefer a clean custom configuration from scratch, place these settings in ~/.tmux.conf: 

# Enable mouse support (scrolling, clicking panes, resizing)
set -g mouse on

# Set default terminal mode to 256 colors
set -g default-terminal "screen-256color"

# Increase scrollback buffer history limit
set -g history-limit 10000

# Start window and pane numbering at 1 instead of 0
set -g base-index 1
setw -g pane-base-index 1

# Renumber windows automatically when one is closed
set -g renumber-windows on

# More intuitive split shortcuts (| for vertical, - for horizontal)
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"
unbind '"'
unbind %

# Use Vi keybindings in copy mode
setw -g mode-keys vi

# Quick reload of tmux config with prefix + r
bind r source-file ~/.tmux.conf \; display "Reloaded tmux config!"

Apply updates immediately inside an active session via: tmux source-file ~/.tmux.conf

5. Oh My Tmux! Setup (.tmux)

Oh My Tmux! is an opinionated, ready-to-use configuration providing a styled status bar, responsive powerline indicators, dual prefix bindings (Ctrl + a and Ctrl + b), and seamless customization through an isolated local file.

Prerequisites

tmux -V
git --version

Installation Steps

  1. Back Up Any Existing Configuration: 
    [ -f ~/.tmux.conf ] && mv ~/.tmux.conf ~/.tmux.conf.bak
  2. Clone the Repository: 
    cd ~
git clone https://github.com/gpakosz/.tmux.git
  3. Create Symlink and Copy Local Template: 
    # Symlink master config
ln -s -f .tmux/.tmux.conf ~/.tmux.conf

# Copy the local settings template
cp .tmux/.tmux.conf.local ~/.tmux.conf.local
  4. Launch a Session: 
    tmux new -s main

Customization & Updates

Make all personal adjustments inside ~/.tmux.conf.local (never directly edit ~/.tmux.conf): 

nano ~/.tmux.conf.local
# or
vim ~/.tmux.conf.local

Powerline Symbols: Enable arrows if using a Powerline/Nerd Font by uncommenting tmux_conf_theme_powerline_symbols=true.

Pulling Updates: Run cd ~/.tmux && git pull.

Reload Shortcut: Hit Ctrl + b then r (or Ctrl + a then r) to reload instantly.
